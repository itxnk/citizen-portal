Run Full Load Test (k6)

Use these commands from your terminal to run the complete load test scenarios: 

# Set ALB hostname
export BASE_URL=http://$(kubectl get ingress -n desc-app \
  -o jsonpath='{.items[0].status.loadBalancer.ingress[0].hostname}')

# Full ramp test (0 → 200 VUs over 13 min — sustained HPA trigger)
k6 run --env BASE_URL=$BASE_URL load-testing/k6/load-test.js

# Demo spike (0 → 300 VUs in 30s — instant scale for evaluation board)
k6 run --env BASE_URL=$BASE_URL load-testing/k6/stress-test.js
